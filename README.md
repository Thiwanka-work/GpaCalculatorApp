# 🎓 Smart GPA Assistant

A premium, modern WPF desktop application designed to help university students calculate, track, and strategically plan their academic performance. Built using **C#** and **.NET 10**, this application offers a sleek, modern dark-themed interface inspired by professional developer tools.

---

## ✨ Features

### 1. 📊 GPA Calculator (Semester-Wise)
* Dynamically add or remove subjects.
* Select credit values (1–5) and letter grades (A+ to F).
* Calculate precise semester GPA instantly with corresponding academic class ratings.

### 2. 📈 CGPA Calculator (Cumulative)
* Combine multiple semesters with different GPA weights and credit hours.
* Keep an ongoing record of your cumulative performance over your entire degree.

### 3. 🎯 Target GPA Planner
* Input your current CGPA, completed credits, and remaining credits.
* Select your target degree class (e.g., *First Class (3.70)*, *Second Upper (3.30)*, *Second Lower (3.00)*).
* The app calculates the exact GPA you need to maintain in your upcoming semesters and provides a difficulty rating.

### 4. 💡 Smart Academic Advisor
* Get personalized, automated feedback based on your current GPA.
* Receive specialized checklists and advice designed to help you study more effectively, manage your time, and reach your goals.

## 🎨 Design & UI/UX Highlights
* **GitHub-Inspired Dark Mode:** Features a gorgeous, high-contrast dark theme (`#0d1117`, `#161b22`) that is highly comfortable for long study sessions.
* **Custom XAML Styling:** Custom-designed buttons with smooth gradients, beautifully styled scrollbars, modern inputs, and clean typography (no heavy external component packages required!).
* **Responsive Sidebar Layout:** Seamless page transition mechanics for a lightweight desktop experience.

## 🚀 How to Run Locally

### Prerequisites
* Windows OS
* [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) or later
* Visual Studio 2022 (with **.NET Desktop Development** workload installed)

### Steps
1. **Clone the Repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/GpaCalculatorApp.git
   ```
2. **Open the Project:**
   Open the folder in Visual Studio or double-click the `GpaCalculatorApp.slnx` or `GpaCalculatorApp.csproj` file.
3. **Build and Run:**
   Press `F5` or click **Start** in Visual Studio to build and run the app.
